## 本版修改

正文采用7幅图：整体框架、指标需求覆盖、三维能力恢复、误差与缺失诊断、可行组合收益权衡、共同冲击配对收益、共享故障响应。Figure 1–7连续编号并在正文引用。

Figure后均为单行标题式短图注；必要的统计含义、区间类型、筛选条件和模拟属性放在邻近正文。图片按原生尺寸置入，未为控制篇幅缩小字体。未继续采用稀疏的独立校准图、箱线图和边际递减图；原模型及相关数值证据保留。

`figures/body_*_en.pdf` 与 `figures/body_*_zh.pdf` 为正文实际引用的矢量图，另附400 DPI PNG。原4幅基础输出仍保留，但不再作为当前正文的完整图集。整体框架的可编辑PPTX位于 `figure_assets/framework_en.pptx`。

风格参考的获奖论文在参考文献中标明，未使用其数值、结论、水印或原图。图标采用改编的Tabler组件，随附MIT许可；本目录不分发图库原图或原论文。

## 编译与模型复现

需已有XeLaTeX。在本目录运行：

```powershell
./build.ps1
```

其他系统可使用 `sh build.sh`。编译依赖包内字体及图件，不需先运行Python。

原模型复现：

```sh
python -m pip install -r code/requirements.txt
python code/run_models.py
python code/export_tables.py
python code/verify_results.py
```

原模型脚本生成数据、结果与基础图，不会重新生成这次人工审核的正文图件。当前图件作为冻结的绘图输出随包提供，LaTeX可以直接编译；不要把模型重跑理解为全部新图的重新绘制。
